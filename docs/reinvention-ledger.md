# Reinvention ledger

How each job from the reinvention audit at `ba7b914` (2026-11-15) was resolved. A job is one behaviour implemented two or more times, built from the audit's SAME and VARIANT verdicts. Each job has one outcome:

- **merged**: one canonical function, callers moved.
- **layering**: one function wraps or delegates to the other, so there is nothing to merge.
- **deliberate**: the difference is intended, and a comment at the definition says why.
- **fixed**: the copies stay separate, but a divergence was a bug and is fixed, with a test that failed before.

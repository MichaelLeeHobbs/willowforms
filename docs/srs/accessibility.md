# Accessibility

How an author builds a form with the keyboard and a screen reader, what the designer and rendered forms show to people with low vision or sensitivity to motion, what every rendered form gives assistive technology, and the accessibility target all of it is checked against. Area code `A11Y`.

What each keyboard operation does to the form belongs to `BUILD` (`BUILD-TREE`, `BUILD-SEL`, `BUILD-DND`, `BUILD-UNDO`); opening and closing the narrow-layout drawers is `WORK-NARR`; moving focus to the step switcher in Preview is `PREV-RUN-14`; the visible required marking is `FILL-ERR-04`; a property's modified marker is `CONF-PROP-14`; declaring a rendered form's language is `LOC-LANG-18`; right-to-left layout, including which way the arrow keys go, belongs to `LOC-DIR`. The theme control and the designer's colour tokens belong to `HOST`, and keeping two designers' labels apart on one page is `HOST-DSGN-04`. The rendered-form rows hold the standard kits; `KIT` leaves a kit's accessibility to this area.

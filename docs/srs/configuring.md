# Configuring components

What an author can set on the selected component in the Inspector, and what the Inspector tells them while they set it. Area code `CONF`.

Translation fields, translation keys and languages belong to `LOC`. Actions and events belong to `ACT`. Which components exist and what each offers belong to `CAT`. Keyboard and screen-reader access to the panels belongs to `A11Y`. Undo steps belong to `BUILD`. Row scope in conditions and Step conditions belong to `FLOW`. What a visibility condition or a rule does to a respondent belongs to `FILL` and `VAL`; refused styling, image sources and refused patterns belong to `SEC`.

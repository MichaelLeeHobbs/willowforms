# Kits

What any component kit must do so the designer and the renderer work with it, how one document moves between kits, and how a host adds components of its own. Area code `KIT`.

What each standard component does for a respondent belongs to `CAT`. The accessibility each kit must provide belongs to `A11Y`. Theming tokens and package boundaries belong to `HOST`. The notice drawn where no kit can draw a component is `FILL-RES-06` and `FILL-RES-07`; loading such a component unchanged is `DOC-LOAD-14`.

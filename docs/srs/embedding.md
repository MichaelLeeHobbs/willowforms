# Embedding and compatibility

What a developer gets when they put the designer or the renderer in their own application: what they pass in and receive, how they theme it, what it runs on, and what the published packages promise. Area code `HOST`.

What the renderer reports and displays is `FILL`; handing documents to the host is `DOC-SAVE`; the host's language input is `LOC-LANG-15` and `LOC-LANG-16`; evaluators, effects and their batches are `ACT`; validating on a server is `VAL-SRV`; shortcuts scoped to the designer and stacking under a host modal are `WORK-SHELL`; hostile documents and author code are `SEC`. What a kit must draw is `KIT`. Contrast, focus and assistive technology are `A11Y`.
